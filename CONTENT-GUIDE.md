# Как добавлять контент на сайт ZAGA GAME

---

## Фотографии клуба

**Главное фото для первого экрана (по желанию):**
положи файл с именем **hero** в `assets/club/`:
`hero.jpg` / `hero.png` / `hero.webp` (регистр не важен).

Остальные фото — с **любыми** именами.

1. Открой папку **assets/club/**
2. Положи туда фотографии (любые имена файлов)
3. Форматы: **jpg, jpeg, png, webp** (можно с большой буквы)
4. В папке сайта выполни одну команду:

```bash
npm run assets
```

или

```bash
node scripts/generate-assets.js
```

5. Обнови страницу в браузере

Если фото нет — сайт работает как обычно, блок «Атмосфера» скрыт.

При `npm run dev` и `npm run build` список фото обновляется **автоматически**.

---

## Обложки игр

1. Положи картинку в **assets/games/** (имя любое, например `photo123.jpg`)
2. Открой файл **js/games.js**
3. У нужной игры укажи путь:

```js
image: "assets/games/photo123.jpg"
```

4. Сохрани файл и обнови страницу

Если картинки нет или `image: ""` — показывается тёмный фон с названием игры, без «битой» картинки.

---

## Отзывы

Открой **js/reviews.js**.

Сейчас там пусто — секция на сайте скрыта.

Чтобы показать отзывы, заполни так:

```js
window.ZAGA_REVIEWS = [
  {
    name: "Анна",
    text: "Текст настоящего отзыва",
    rating: 5,
    source: "Яндекс Карты"
  }
];
```

Общий рейтинг (по желанию):

```js
window.ZAGA_RATING = { value: 4.9, count: 27, source: "Яндекс Карты" };
```

Пиши только реальные отзывы.

## Запуск сайта

```bash
npm run dev
```

Откроется локальный сервер (обычно http://localhost:3000).

Перед запуском и перед «сборкой» фото клуба подхватываются сами.

| Обложка игры | assets/games/ + js/games.js | указать image |
