# ZAGA GAME — сайт-визитка VR-клуба (Бобруйск)

Премиальный одностраничный лендинг.

## Структура
- `index.html` — секции: Hero → Intro → Experience → Games → Why → Prices → Atmosphere → CTA → Contacts
- `css/style.css` — визуальная система (#F403FD only)
- `js/preloader.js` — typewriter preloader
- `js/main.js` — навигация, игры (featured), тарифы (будни/выходные), звук (desktop only)
- `assets/logo.svg` — логотип

## Запуск
Открой `index.html` локально или опубликуй через GitHub Pages.

## Данные
Цены и игры — массивы в `js/main.js`.
